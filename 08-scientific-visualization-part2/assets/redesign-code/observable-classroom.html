Observable Notebook: classroom demo and sharing guide

For Observable Notebooks 2.0: add 9 separate JavaScript (js) cells to a blank notebook. The data is embedded, and each specification can be edited directly. Complete setup and sharing guide · Chart previews / JSON

Updated for Notebooks 2.0: replace the earlier cells with the code below. This version uses import, const, a DOM container and display(). It fixes the Assignment to external variable error from legacy cell syntax.

  1. Copy the import embed cell first to load the charting library.
  2. Copy each specification and chart output in the order below to draw the four charts.
  3. Edit height in gainSpec, run the cell and watch gainChart update. Try different colors and annotations too.
  4. Add Markdown cells for explanations and sources. In Settings, choose Unlisted or Public access and copy the URL. Students can Fork their own copies. See the user guide.
