How to run and read this example

From this project folder, run python3 -m http.server 8000, then open http://localhost:8000/tree.html. Use HTTP rather than opening the file directly.

Read js/tree.js. It imports the existing loadData() and buildTree(), calls d3.hierarchy() and d3.tree(), then draws links and nodes.

This tree layout does not require .sum(). Node size and spacing show structure, not passenger counts or survival rates.

On a narrow screen, scroll the chart horizontally to keep the labels readable.
