How to run and read this example

From this project folder, run python3 -m http.server 8000, then open http://localhost:8000/. ES modules and CSV loading require HTTP; do not double-click the HTML files.

Start with js/main.js, then read data.js → buildTree.js → treemap.js. For Stage 2, read interaction.js and its one call in main.js.
