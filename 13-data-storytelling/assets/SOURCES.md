## Bloomberg / NASA GISS 数据重绘

下载于 2026-10-08，直接使用原作公开链接：

- bloomberg-observed.csv：https://www.bloomberg.com/graphics/2015-whats-warming-the-world/data/observed.csv
- bloomberg-forcings.csv：https://www.bloomberg.com/graphics/2015-whats-warming-the-world/data/forcings.csv

生成脚本：../render-storytelling.py（Python 标准库，SVG 原生路径）。运行后生成 warming-normalized.csv 及六幅 warming-*.svg。

处理方法：

1. 观测使用 Annual_Mean，模型使用原始 named field；不使用 5-year_Mean，不填补、不插值。
2. 每条序列减去其自身 1880–1910（含首尾，31 年）均值，与原作文字说明的共同基线方式一致。
3. 观测原表为温度距平、模型原表为开尔文绝对温度。去均值后的温差以摄氏度表示；开尔文差值与摄氏度差值数值相同。
4. 全部重绘使用 1880–2005 的共同范围（126 个年值）、同一纵轴范围和像素坐标；原站开场更长的观测记录不用于重绘。
5. Natural 和 All forcings 使用原始模型列，绝非简单相加 individual factor。各模型列本身按原站方法说明为多次模拟的平均。
6. 重绘不复刻原站 Fahrenheit 标度或置信区间。图注统一写 Course replot / NASA GISS data distributed by Bloomberg；不冒充原始截图或完整原作。
7. Context / natural / greenhouse / combined 为四个压缩教学阶段；真实作品还有其它因素的中间页面。
8. all-at-once 和 comparison 是教学组织视图，不声称是原站某个精确页面。
